## 1. 플랫폼 개요

### 1.1 QUASA란?

**QUASA (QUAntitative Stock Analysis)**는 전자공시시스템 연동 프리미엄 기업 분석 플랫폼으로, 다음과 같은 핵심 가치를 제공합니다:

- **파편화된 공시 데이터 통합**: AI가 수백 장의 사업보고서를 핵심 키워드로 시각화
- **실시간 주가 연동**: 재무 지표와 주가의 상관관계를 실시간으로 분석
- **AI 퀀트 분석**: 데이터에 기반한 객관적인 기업 등급 산출
- **산업 리포트**: 업종 내 주요 지표의 순위와 변화를 한눈에 파악

### 1.2 주요 기능 구성

| 메뉴 | 핵심 기능 |
|------|----------|
| **대시보드** | 시장 지수, 산업별 순위, 실시간 공시, 시가총액 랭킹 |
| **기업비교** | 다중 기업 재무지표 비교, 저평가 분석, 투자지표 비교 |
| **산업** | 산업 지수 추이, 다차원 필터링, 뉴스/키워드 분석 |
| **기업 상세** | 주가 분석, 재무 데이터, AI 전망 분석, 공시 이력 |

## 2. 퀀트 투자자 페르소나

```

직업: 개인 퀀트 투자자 / 자산운용사 애널리스트
투자 성향: 데이터 기반 가치투자 + 모멘텀 전략 혼합
주요 관심사:
  - 저평가된 성장주 발굴
  - 산업별 섹터 로테이션
  - 재무제표 기반 팩터 투자
  - 공시 이벤트 기반 투자
```

### 2.2 투자 의사결정 프로세스

```
[시장 스캐닝] → [섹터 분석] → [종목 스크리닝] → [심층 분석] → [투자 결정] → [모니터링]
```

## 3. 사용 시나리오

### 시나리오 1: 일간 시장 모니터링 (Morning Routine)

**목표**: 시장 전체 흐름 파악 및 주요 공시 확인

#### Step 1: 대시보드 접속

```
경로: 로그인 → 대시보드
소요 시간: 5분
```

**확인 항목**:

| 항목 | 확인 내용 | 투자 활용 |
|------|----------|----------|
| KOSPI/KOSDAQ 지수 | 전일 대비 등락률 | 시장 심리 파악, 현금 비중 조절 |
| 산업 순위 | 시가총액 기준 상위 산업 | 섹터 로테이션 신호 |
| 자본시장 공시 | 자기주식 취득/처분, 감자 결정 등 | 이벤트 드리븐 투자 기회 |
| 시가총액 순위 | 등락률 상위/하위 종목 | 모멘텀/역행 투자 후보 |

**의사결정 포인트**:
- 특정 산업 지수가 급등락 → 해당 산업 심층 분석
- 주요 공시(자기주식 취득) 발생 → 해당 기업 상세 분석

---

### 시나리오 2: 산업 섹터 분석 (Sector Rotation Strategy)

**목표**: 유망 산업 발굴 및 해당 산업 내 핵심 종목 선별

#### Step 2-1: 산업 페이지 접속

```
경로: 산업 → 산업 선택 (예: 전기·전자)
소요 시간: 10분
```

**분석 프로세스**:

1. **산업 지수 추이 확인**
   - 1M/3M/6M/1Y 기간별 차트 분석
   - 상승 추세 산업 → 모멘텀 투자
   - 하락 후 반등 신호 산업 → 역발상 투자

2. **다차원 가치 지표 필터링**

   | 지표 | 필터 조건 (예시) | 투자 논리 |
   |------|-----------------|----------|
   | PER | 0 ~ 15 | 저평가 종목 선별 |
   | PBR | 0 ~ 2 | 자산가치 대비 저평가 |
   | ROE | 10% ~ 30% | 수익성 우량 기업 |
   | 부채비율 | 0 ~ 100% | 재무 안정성 |
   | 배당수익률 | 2% ~ 10% | 현금 흐름 + 배당 수익 |

3. **산업 내 기업 순위 확인**
   - 시가총액, ROE 기준 정렬
   - 미니차트로 단기 주가 흐름 파악

4. **산업 이슈 키워드 분석**
   - 워드클라우드에서 주요 테마 확인 (예: "HBM", "AI 반도체")
   - 뉴스 섹션에서 산업 동향 파악

**의사결정 포인트**:
- 필터 조건 충족 기업 → 기업 상세 페이지로 이동
- 키워드 트렌드와 일치하는 기업 → 우선 분석 대상

---

### 시나리오 3: 저평가 성장주 스크리닝 (Value + Growth)

**목표**: PER-YoY 분석을 통한 저평가 고성장 기업 발굴

#### Step 3-1: 기업비교 페이지 활용

```
경로: 기업비교 → 비교 세트 생성 → 기업 추가
소요 시간: 15분
```

**핵심 분석 도구: 이익 성장성 대비 저평가 분석**

```
차트 해석:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
         │
  고PER   │   ◆ 고평가 + 저성장
  (비쌈)  │      (주의 필요)
         │
─────────┼─────────────────────
         │
  저PER   │   ★ 저평가 + 고성장
  (저렴)  │      (매력적 투자처)
         │
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
        저YoY          고YoY
       (저성장)        (고성장)
```

**투자 논리**:
- **좌측 하단(★)**: 저PER + 고YoY = 시장이 아직 인식하지 못한 성장주
- **우측 상단(◆)**: 고PER + 저YoY = 성장 둔화에도 고평가 유지, 하락 리스크

**비교 세트 구성 예시**:
```
비교 세트: "반도체 빅3 분석"
- 삼성전자(주)
- 에스케이하이닉스(주)
- 한미반도체(주)
```

**추가 분석 지표**:

| 탭 | 확인 지표 | 활용 |
|----|----------|-----|
| 매출액 | 연도별 추이 | 성장성 확인 |
| 영업이익 | 이익률 변화 | 수익성 개선 여부 |
| 주가 추이 | 6개월 차트 | 기술적 분석 보완 |
| 투자 지표 | EPS, ROE, PBR | 밸류에이션 비교 |

---

### 시나리오 4: 개별 종목 심층 분석

**목표**: 투자 대상 기업의 펀더멘탈 및 전망 종합 분석

#### Step 4-1: 기업 상세 페이지 진입

```
경로: 검색 또는 산업 순위 → 기업 클릭
소요 시간: 20분
```

**분석 체크리스트**:

##### 1) 기업정보 탭
- [ ] 산업/시장 분류 확인
- [ ] 시가총액 규모 파악
- [ ] 대표자 및 기업 연혁

##### 2) 주가 탭
- [ ] 실시간 주가 차트 (1D/1W/1M/1Y)
- [ ] 시가/종가/고가/저가 확인
- [ ] 동종업계 내 순위 및 상대 강도

##### 3) 재무분석 탭
- [ ] **사업분석**: 매출 포트폴리오 (주력/신규/해외/기타)
- [ ] **매출액 추이**: YoY 성장률
- [ ] **영업이익 추이**: 이익률 개선 여부
- [ ] **당기순이익 추이**: 최종 수익성
- [ ] **순익흐름도 (산키 다이어그램)**: 비용 구조 파악

```
순익흐름도 해석:
총매출 → 비용구조 → 원가비용 → 판관비 → 순수익

투자 포인트:
- 원가비율 감소 = 원가 경쟁력 개선
- 판관비 감소 = 운영 효율성 향상
- 순이익률 증가 = 투자 매력도 상승
```

##### 4) 기업전망 탭 (AI 분석)
- [ ] **전망 요약**: AI가 분석한 핵심 인사이트
- [ ] **긍정적 요인**: 성장 동력, 경쟁 우위
- [ ] **리스크 요인**: 잠재적 위험 요소
- [ ] **투자 의견**: 매수/관망/매도 권고
- [ ] **목표 주가**: AI 산출 적정 가격

##### 5) 뉴스 탭
- [ ] 최신 뉴스 헤드라인 확인
- [ ] 긍정/부정 뉴스 비율 파악

##### 6) 공시 탭
- [ ] **주요공시**: 자기주식, 유상증자, 감자 등
- [ ] **공시분석**: AI 요약 확인
- [ ] DART 원문 링크 확인

---

### 시나리오 5: 포트폴리오 구성 및 모니터링

**목표**: 분석 결과를 바탕으로 포트폴리오 구성 및 지속 관리

#### Step 5-1: 관심 종목 등록

```
경로: 기업 상세 → 관심 버튼 클릭
활용: 사이드바에서 관심 종목 빠른 접근
```

#### Step 5-2: 비교 세트 저장

```
경로: 기업비교 → 세트 추가하기
활용: 포트폴리오 vs 벤치마크 비교
```

**포트폴리오 구성 예시**:

| 구분 | 종목 | 비중 | 투자 근거 |
|------|-----|-----|----------|
| 핵심 | 삼성전자 | 30% | HBM 성장, 저PER |
| 핵심 | SK하이닉스 | 25% | AI 수혜, ROE 우수 |
| 성장 | 한미반도체 | 20% | 고YoY, 기술력 |
| 안정 | 신한금융지주 | 15% | 배당수익률, 저PBR |
| 현금 | - | 10% | 추가 매수 대기 |

#### Step 5-3: 일간/주간 모니터링

**일간 체크 항목**:
- 대시보드: 주요 공시 확인
- 관심 종목: 주가 변동 확인
- 뉴스: 보유 종목 관련 이슈

**주간 체크 항목**:
- 산업 지수 변화
- 비교 세트 재무지표 업데이트
- 투자 의견 변화 여부

## 4. 퀀트 투자 전략별 활용법

### 4.1 팩터 투자 (Factor Investing)

| 팩터 | QUASA 활용 방법 |
|------|----------------|
| **Value** | 산업 필터에서 PER, PBR 낮은 종목 |
| **Quality** | ROE 높은 종목, 영업이익률 상승 종목 |
| **Momentum** | 주가 추이 차트, 등락률 상위 종목 |
| **Size** | 시가총액 순위 하위권 (소형주 전략) |
| **Dividend** | 배당수익률 필터 활용 |

### 4.2 이벤트 드리븐 (Event-Driven)

| 이벤트 | QUASA 활용 방법 |
|--------|----------------|
| 자기주식 취득 | 대시보드 공시 모니터링 |
| 실적 발표 | 기업 상세 → 재무분석 탭 |
| 주요 계약 체결 | 공시 탭 → DART 링크 |
| 산업 정책 변화 | 산업 뉴스 섹션 |

### 4.3 섹터 로테이션 (Sector Rotation)

```
[경기 확장기] → 전기·전자, IT 서비스 비중 확대
[경기 둔화기] → 금융, 유틸리티 비중 확대
[금리 상승기] → 은행/보험 주목
[금리 하락기] → 성장주 (반도체, 바이오) 주목
```

**QUASA 활용**:
1. 산업별 지수 추이 비교
2. 산업 간 ROE, PER 비교
3. 산업 이슈 키워드로 트렌드 파악

## 6. 결론

QUASA는 퀀트 투자자가 필요로 하는 **정량적 분석**과 **정성적 분석**을 모두 지원하는 통합 플랫폼입니다.

**핵심 가치**:
1. 분산된 데이터를 한 곳에서 확인
2. 복잡한 재무제표를 직관적으로 시각화
3. AI 기반 투자 인사이트 제공
4. 실시간 데이터로 신속한 의사결정 지원

**권장 사용 패턴**:
```
매일 아침: 대시보드 → 공시 확인 → 관심 종목 체크
주 1회: 산업 분석 → 섹터 비중 조절
월 1회: 기업비교 → 포트폴리오 리밸런싱
분기 1회: 재무분석 → 실적 발표 후 전략 수정
```
