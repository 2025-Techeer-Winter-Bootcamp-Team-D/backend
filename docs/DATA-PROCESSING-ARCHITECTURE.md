## 개요

본 시스템은 **금융 데이터 시각화 및 AI 기반 기업/산업 전망 분석**을 위한 백엔드 플랫폼입니다.

### 핵심 목표

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        💡 핵심 가치 제안                                  │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  📊 기업 정보 시각화    →   DART API + 재무제표 + 시가총액                  │
│                                                                         │
│  📰 뉴스/보고서 분석    →   AI 요약 + 감성분석 + 벡터 임베딩                │
│                                                                         │
│  🔍 벡터 검색          →   OpenSearch HNSW + 코사인 유사도                 │
│                                                                         │
│  📈 기업/산업 전망     →   뉴스 클러스터링 + 키워드 빈도 + 트렌드 분석       │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

## 뉴스 크롤링 및 AI 분석 파이프라인

### Celery Canvas 6단계 파이프라인

```
┌─────────────────────────────────────────────────────────────────────────────────────┐
│                          뉴스 처리 파이프라인 상세 흐름                                │
└─────────────────────────────────────────────────────────────────────────────────────┘

키워드 입력: ["AI", "반도체", "삼성전자", "SK하이닉스"]
        │
        ▼
┌───────────────────────────────────────────────────────────────────────────────────┐
│ 1️⃣  검색 단계 (Search Phase)                                                      │
│     ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━     │
│                                                                                   │
│     ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐                       │
│     │   "AI"   │  │ "반도체"  │  │"삼성전자" │  │"SK하이닉스"│     ← Celery group  │
│     └────┬─────┘  └────┬─────┘  └────┬─────┘  └────┬─────┘       (병렬 실행)     │
│          │             │             │             │                             │
│          ▼             ▼             ▼             ▼                             │
│     ┌─────────────────────────────────────────────────────┐                      │
│     │              Naver News Search API                  │                      │
│     │              (키워드당 최대 10개 기사)                │                      │
│     └─────────────────────────────────────────────────────┘                      │
│          │             │             │             │                             │
│          └─────────────┴─────────────┴─────────────┘                             │
│                              │                                                   │
│                              ▼                                                   │
│     ┌─────────────────────────────────────────────────────┐                      │
│     │           aggregate_search_results                  │  ← chord callback   │

│     └─────────────────────────────────────────────────────┘                      │
│                              │                                                   │

│                                                                                   │

        │
        ▼
┌───────────────────────────────────────────────────────────────────────────────────┐
│ 2️⃣  본문 추출 단계 (Extraction Phase)                                             │
│     ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━     │
│                                                                                   │
│     ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐                       │
│     │ Article1 │  │ Article2 │  │ Article3 │  │  ...     │     ← Celery group   │
│     └────┬─────┘  └────┬─────┘  └────┬─────┘  └────┬─────┘       (병렬 실행)     │
│          │             │             │             │                             │
│          ▼             ▼             ▼             ▼                             │
│     ┌─────────────────────────────────────────────────────┐                      │
│     │                  Trafilatura                        │                      │
│     │          (HTML → Markdown 변환)                     │                      │
│     │          (광고, 메뉴, 댓글 자동 제거)                 │                      │
│     └─────────────────────────────────────────────────────┘                      │
│          │             │             │             │                             │
│          └─────────────┴─────────────┴─────────────┘                             │
│                              │                                                   │
│                              ▼                                                   │
│     ┌─────────────────────────────────────────────────────┐                      │
│     │         aggregate_extraction_results                │  ← chord callback   │
│     │         (실패 항목 필터링, 최소 100자 체크)            │                      │
│     └─────────────────────────────────────────────────────┘                      │
│                              │                                                   │
│     출력: [{..., raw_content: "뉴스 본문..."}, ...]                               │
│                                                                                   │
└───────────────────────────────────────────────────────────────────────────────────┘
        │
        ▼
┌───────────────────────────────────────────────────────────────────────────────────┐
│ 3️⃣  정제 + 요약 단계 (Processing Phase)                                           │
│     ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━     │
│                                                                                   │
│     각 기사에 대해 병렬 처리 (Celery group):                                        │
│                                                                                   │
│     ┌─────────────────────────────────────────────────────────────────────────┐  │
│     │                                                                         │  │
│     │  raw_content ──┬──► RefineService (Gemini 2.5 Flash)                   │  │
│     │                │    • Markdown 메타데이터 제거                           │  │
│     │                │    • HTML 태그 제거                                    │  │
│     │                │    • 광고/메뉴 텍스트 제거                              │  │
│     │                │    • 프롬프트 인젝션 방지                               │  │
│     │                │                                                        │  │
│     │                │         ▼                                              │  │
│     │                │    refined_content (정제된 본문)                        │  │
│     │                │                                                        │  │
│     │                └──► SummarizeService (Gemini 2.5 Flash)                 │  │
│     │                     • 3줄 이내 요약 생성                                 │  │
│     │                     • 감성 분석 (positive/neutral/negative)             │  │
│     │                     • JSON 출력 형식                                    │  │
│     │                                                                         │  │
│     │                          ▼                                              │  │
│     │                     {summary, sentiment}                                │  │
```

#### RabbitMQ vs Redis (브로커 선택 이유)

```
┌─────────────────────────────────────────────────────────────────────────────────────┐
│                     RabbitMQ를 메시지 브로커로 선택한 이유                             │
└─────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────┐        ┌─────────────────────────────────┐
│           RabbitMQ              │        │             Redis               │
│        (메시지 브로커)           │        │       (Result Backend)          │
├─────────────────────────────────┤        ├─────────────────────────────────┤
│                                 │        │                                 │
│ ✅ 메시지 영속성 (디스크 저장)    │        │ ✅ 빠른 읽기/쓰기               │
│ ✅ 메시지 확인(ACK) 메커니즘      │        │ ✅ TTL 기반 자동 만료           │
│ ✅ 우선순위 큐 지원              │        │ ✅ 단순한 키-값 구조            │
│ ✅ 라우팅 및 토픽 기반 분배       │        │ ✅ Pub/Sub 지원                │
│ ✅ 고가용성 클러스터링            │        │                                 │
│ ✅ 메시지 재전송 보장             │        │ ❌ 메시지 유실 가능성           │
│                                 │        │ ❌ 복잡한 라우팅 불가            │
│                                 │        │                                 │
│ 용도: 태스크 메시지 전달          │        │ 용도: 태스크 결과 저장          │
│       (신뢰성 중요)              │        │       (속도 중요)               │
│                                 │        │                                 │
└─────────────────────────────────┘        └─────────────────────────────────┘

선택 근거:
• 뉴스 크롤링은 장시간 실행되는 중요 태스크 → 메시지 유실 방지 필수
• 다양한 태스크 유형 → 큐 우선순위 및 라우팅 필요
• 시스템 재시작 시에도 미처리 태스크 보존 필요
```

| **임베딩** | Gemini text-embedding-004 | 768차원 벡터 생성 |
| **클러스터링** | scikit-learn DBSCAN | 뉴스 중복 제거, 이슈 탐지 |
