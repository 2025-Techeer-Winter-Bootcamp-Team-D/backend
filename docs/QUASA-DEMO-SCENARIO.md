# QUASA 데모 영상 시나리오 (4분)

> **총 러닝타임**: 3분 50초
> **컨셉**: 퀀트 투자자의 아침 루틴 - "오늘의 투자 기회 찾기"

---

## 오프닝 (0:00 - 0:15) ⏱️ 15초

**화면**: 메인 페이지 랜딩

**나레이션**:
> "복잡한 재무제표, 수백 페이지의 사업보고서...
> QUASA가 데이터로 읽어드립니다."

**액션**:
- 메인 페이지 슬로건 노출: *"기업의 가치, 데이터로 읽다"*
- "지금 시작하기" 클릭

---

## Scene 1: 시장 한눈에 보기 (0:15 - 0:45) ⏱️ 30초

**화면**: 대시보드

**나레이션**:
> "퀀트 투자자의 하루는 시장 전체를 스캔하는 것에서 시작합니다."

**액션 & 포인트**:

| 시간 | 액션 | 강조 포인트 |
|------|------|------------|
| 0:15 | KOSPI/KOSDAQ 지수 카드 보여주기 | "실시간 시장 지수" |
| 0:25 | 산업 순위 → 전기·전자 클릭 | "시가총액 기준 산업 순위" |
| 0:35 | 자본시장 공시 스크롤 | "DART 연동 실시간 공시" |

**전환 멘트**:
> "오늘 전기·전자 섹터가 눈에 띄네요. 더 자세히 분석해볼까요?"

---

## Scene 2: 산업 깊게 파보기 (0:45 - 1:30) ⏱️ 45초

**화면**: 산업 페이지 (전기·전자 선택)

**나레이션**:
> "산업 전체를 조망하고, 원하는 조건의 기업만 필터링합니다."

**액션 & 포인트**:

| 시간 | 액션 | 강조 포인트 |
|------|------|------------|
| 0:45 | 산업 지수 차트 (6M) | "산업 지수 상승 추세 확인" |
| 0:55 | **다차원 필터** 조작 | ⭐ **핵심 기능** |
| - | PER 슬라이더: 0~15 | "저평가 기업만" |
| - | ROE 슬라이더: 10%+ | "수익성 우량 기업만" |
| 1:10 | 필터 적용 후 기업 수 변화 | "12개 → 3개로 압축" |
| 1:20 | 산업 키워드 워드클라우드 | "HBM, AI 반도체가 핫이슈" |

**전환 멘트**:
> "삼성전자, SK하이닉스, 한미반도체가 조건에 맞네요. 비교해봅시다."

## Scene 3: 경쟁사 비교 분석 (1:30 - 2:20) ⏱️ 50초

**화면**: 기업비교 페이지

**나레이션**:

**액션 & 포인트**:

| 시간 | 액션 | 강조 포인트 |
|------|------|------------|
| 1:30 | 비교 세트 선택 | "반도체 빅3 비교" |
| 1:40 | 영업이익 차트 탭 전환 | "매출 → 영업이익 → 순이익" |
| 1:55 | **PER-YoY 버블 차트** | ⭐ **핵심 기능** |
| - | 좌하단 영역 강조 | "저평가 + 고성장 = 매력적!" |
| 2:10 | 투자지표 탭 (ROE 선택) | "ROE 비교로 수익성 확인" |

**전환 멘트**:
> "SK하이닉스가 저평가 고성장 영역에 있네요. 더 깊이 분석해봅시다."

## 데모 체크리스트

### 사전 준비

- [ ] 로그인 상태 확인
- [ ] 비교 세트 "반도체 빅3" 미리 생성 (삼성전자, SK하이닉스, 한미반도체)
- [ ] 관심 종목에 주요 기업 등록
- [ ] 브라우저 북마크/탭 정리

### 화면 설정

- [ ] 브라우저 전체화면 (F11)
- [ ] 확대 비율 100% 또는 110%
- [ ] 다크모드/라이트모드 통일

### 녹화 팁

- 마우스 움직임은 천천히, 부드럽게
- 클릭 전 0.5초 정도 호버 상태 유지
- 로딩 시간 고려하여 여유 있게 진행
